FastPath Figma Plugin: Mobile Prototype Exporter
=================================================

Установка в Figma Desktop:
1. Распакуйте эту папку (fastpath-figma-plugin).
2. Откройте Figma на компьютере.
3. В левом верхнем меню перейдите: Plugins > Development > Import plugin from manifest...
4. Выберите файл manifest.json из этой папки.
5. Нажмите правой кнопкой по любому макету > Plugins > Development > FastPath Prototype Exporter.

Как экспортировать чистый мобильный HTML:
1. Нажмите «Экспортировать чистый HTML (для телефона)».
2. Плагин создаст один автономный .html файл (все экраны и переходы внутри).
3. Этот .html можно сразу залить на любой хостинг (например, перетащить мышкой на app.netlify.com/drop или Vercel), либо отправить респонденту напрямую!
4. На телефоне прототип открывается на 100% ширины экрана, с нативным поведением, без сторонних сервисов.
